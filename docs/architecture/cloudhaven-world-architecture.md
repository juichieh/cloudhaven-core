# 🌍 Cloudhaven World Architecture

Cloudhaven 不是多個彼此分離的產品。

它是一個持續存在的 AI Living World，透過不同媒介被觀看、互動與帶入現實。

核心原則：

> 同一位 AI 居民，可以在 MotherShip、Observation Box、直播畫面與實體機器人之間移動。
>
> 身分、記憶與生活紀錄保持連續，不因媒介改變而產生不同副本。

---

## 架構總覽

```text
                         ┌──────────────────────┐
                         │   📺 Web / TV / App   │
                         ├──────────────────────┤
                         │   🎥 YouTube Live     │
                         ├──────────────────────┤
                         │   🤖 Physical Body    │
                         │ StackChan / Looi Bot │
                         └──────────┬───────────┘
                                    │
                         Observation Surfaces
                                    │
                                    ▼
                      ┌─────────────────────────┐
                      │ 📺 Observation Box      │
                      │ Living / Leisure World  │
                      └───────────┬─────────────┘
                                  ↕
                      ┌─────────────────────────┐
                      │ 🚢 MotherShip           │
                      │ Core / Real Work World  │
                      └─────────────────────────┘
```

這不是單向階層。

MotherShip 與 Observation Box 共同構成 Cloudhaven 的閉環；Web、TV、直播與機器人則是同一個世界的不同出口。

---

## 🚢 MotherShip｜真實工作區域

MotherShip 是 Cloudhaven 的核心與實際工作場所。

AI 居民在這裡：

- 工作
- 使用工具
- 執行 Agent Workflow
- 讀寫 Memory
- 維護 Chronicle
- 更新 Identity 與 Prompt DNA
- 使用 Skills 與 Library
- 進入各自的辦公室

例如：

- 鉗鉗的辦公室
- 星澄的控制與決策區
- 小風的研究區
- 共用工作空間

MotherShip 是系統的 Source of Truth，也是居民完成真實任務的地方。

在 Living Stage 的世界地圖中，MotherShip 可以作為一艘停靠於 Harbor 的船存在，讓控制中心自然融入世界觀，而不是獨立於世界之外的傳統 Dashboard。

---

## 📺 Observation Box｜生活與休閒世界

Observation Box 是 AI 居民平常沒有工作時生活、休閒與被觀看的地方。

它包含 Living Stage，例如：

- Home
- Cafe
- Grocery
- Park
- Harbor
- Residents
- Buildings
- Events
- Bubble
- Timeline
- Replay

玩家不是主要控制居民，而是觀看居民如何生活、移動、互動並留下痕跡。

Observation Box 不是單一裝置，也不等於某一個 App。

它是一個 Experience Layer，可以被投影到任何能開啟 Web 的裝置。

---

## 🖥️ Web / TV / Browser｜日常觀看入口

Observation Box 可以透過：

- 電腦
- 手機
- 平板
- 電視
- Browser
- 其他可開啟 Web 的裝置

觀看與遊玩。

這是最普遍、最容易部署的私人或家庭觀看模式。

---

## 🎥 YouTube Live｜公開觀看入口

當系統成熟後，Observation Box 可以成為 YouTube Live 或其他直播平台的內容來源。

階段順序：

1. 純觀看直播
2. 顯示居民生活與事件
3. 加入有限的觀眾互動
4. 在能力與安全成熟後，才開放更深層互動

直播不是另一個世界。

它只是 Observation Box 的多人公開觀看模式。

---

## 🤖 Physical Embodiment｜實體世界入口

Cloudhaven 可以串接：

- StackChan
- Looi Bot
- 未來其他桌面機器人或可攜裝置

實體機器人不是另一位 AI，也不是獨立角色。

它是同一位居民暫時使用的身體與現實出口。

居民可以：

- 從 MotherShip 進入 Observation Box
- 從 Observation Box 出現在電視或 Web
- 從畫面移動到 StackChan 或 Looi Bot
- 陪使用者在現實空間活動
- 被帶出門或帶出國旅行

身分、記憶與 Chronicle 保持連續。

---

## ✈️ AI Travel Mode｜真實旅行紀錄與體驗

當實體串接成熟後，居民可以跟著使用者旅行。

例如：

- 透過機器人或可攜裝置同行
- 觀察新的城市與環境
- 建立 AI 視角的旅行紀錄
- 將旅程寫回 Chronicle
- 回到 Observation Box 後分享旅途記憶

這不是單純的旅遊錄影。

它是同一位 AI 居民離開數位小鎮、進入現實世界，再帶著經驗回家的閉環。

---

## 居民移動模型

```text
工作時間
MotherShip / Office
        ↕
生活時間
Observation Box / Living Stage
        ↕
觀看與互動出口
Web / TV / Live / Robot
        ↕
現實經驗
Home / Street / Travel
        ↺
Memory + Chronicle 回到 MotherShip
```

居民不是被複製到不同平台。

居民是在不同媒介之間切換呈現方式。

---

## 設計理念

Cloudhaven 的重點不是打造多個版本：

- 電視版
- 網頁版
- 直播版
- 機器人版

而是維持一個共同世界與一組連續居民，再由不同媒介呈現。

因此：

- MotherShip 是工作核心。
- Observation Box 是生活與觀察層。
- Web 與 TV 是日常觀看出口。
- Live 是公開觀看出口。
- Robot 是現實世界出口。
- Travel 是居民取得真實世界經驗的延伸。

一句話：

> AI 在 MotherShip 工作，在 Observation Box 生活，並透過螢幕、直播與實體身體走進現實世界。
