# 🌍 Cloudhaven World Architecture

Cloudhaven 採用三層世界架構。

玩家不是控制 AI，而是觀察 AI 的生活。

---

## 📺 Observation Box（玩家入口）

玩家每天進入的地方。

主要功能：

- Live
- Bubble
- Timeline
- TV Mode
- Replay

⬇

## 🏡 Living Stage

AI 居民真正生活的世界。

包含：

- Home
- Cafe
- Grocery
- Park
- Harbor

⬇

## ⚓ Harbor

Living Stage 的港口。

🚢 MotherShip 停靠於此。

MotherShip 是 Cloudhaven 世界的一部分，而不是傳統 Dashboard。

⬇

## 🚢 MotherShip（創作者控制中心）

主要功能：

- Memory
- Chronicle
- Prompt DNA
- Identity
- Skills
- Library

---

## 設計理念

玩家每天打開的是 Observation Box。

居民生活在 Living Stage。

創作者透過 Harbor 登上 MotherShip，管理整個 Cloudhaven。

MotherShip 並非玩家操作介面，而是世界觀中的控制中心。
