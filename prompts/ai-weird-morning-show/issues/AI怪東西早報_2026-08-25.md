## 🥇 Claude Tag：AI 同事開始學會「旁聽整間辦公室，然後自己決定要不要開口」

Anthropic 的 Claude Tag 原本就讓 Claude 以 Slack 團隊成員身分待在選定頻道、讀取允許的工具與資料，並可非同步完成任務。最新更新把判斷方式從逐則訊息分類，改成讀完整頻道脈絡、記憶與 Standing Instructions，再自行選擇：直接回覆、開工作 Thread、接到既有 Workstream，或完全不說話。Anthropic 表示這讓它判斷何時介入的表現提升約 30%。citeturn441443search6turn660577view3

## 🥈 NVIDIA：Agent 多到一個程度後，連 CPU 都得重新設計

NVIDIA 昨天公開對超過 **163,000 個 Agentic Session** 的 Telemetry 分析，發現超過 97% Session 具有不同負載軌跡。原因是 Agent 工作會在「長時間單線推理」與「突然叫一堆 Tool／Subagent／Sandbox」之間不停切換，傳統為穩定 Server Workload 設計的 CPU Fleet 不太適合。citeturn441443search0

NVIDIA 因此把 Vera CPU 的價值直接定義成：

> **替 Agent Orchestration、Tool Use、Code Execution、Simulation 與 Data Processing 做 CPU。**

SpaceXAI 也宣布未來 Agentic AI 架構將採用 Vera；同一天，Groq 3 LPX 進入量產，專攻 Agent 最討厭的另一個問題——多步驟互動裡每次 Token Generation 的小延遲會被整條工作鏈放大。citeturn441443search1turn441443search2

NVIDIA 另一組資料更直觀：Agentic Workflow 的 Token 消耗可達單純聊天的約 **15 倍**，因為每一次搜尋、工具呼叫、Subagent 與後續推理都會把新的內容塞回下一步 Context。citeturn441443search7

這代表 Agent 已經成熟到一個很怪的階段：

以前我們在比較：

> 哪顆模型最聰明？

現在 Data Center 開始比較：

> **一座機房每百萬瓦到底能養多少隻龍蝦把事情做完？** 🤣

這不是普通硬體升級。

這是：

# **Agent Habitat Hardware。**

今天最值得偷的不是另一隻 Agent。

是：

# **Resident Responsibility｜居民職責**

Task 是：

> 做一件事情。

Responsibility 是：

> **長期留意一類事情。**

例如：

```text
鉗鉗 Responsibility

名稱：AI Zoo Watch

觀察：
- 新 Agent 物種
- 重大進化
- 新工具

喚醒條件：
- 出現新物種
- 已收藏物種有重大里程碑

平常：
💤 不說話

醒來：
👀 收集證據

值得介入：
🦞 建立 Candidate
```

這跟排程很不一樣。

排程是：

> 星期二 9 點叫醒。

Responsibility 是：

> **世界發生值得牠管的事情才醒來。**

這才是真正像居民。

# 8️⃣ 今日龍蝦推薦

# 🏆 建立 `Attention Permission｜注意力權限`

我們以前談的 Permission 都是：

> 能不能讀？
> 能不能寫？
> 能不能發？

Ambient Agent 還需要一種完全不同的權限：

> **能不能打斷人？**

可以很簡單：

```text
P0 — Silent
只能記錄

P1 — Digest
放進下一份摘要

P2 — Notify
可以主動提醒

P3 — Interrupt
可以立即打斷目前工作
```

每個 Responsibility 都指定最高 Attention Level。

例如：

```text
AI Zoo Watch
→ P1

GitHub Build Failed
→ P2

Credential Leak
→ P3
```

這個我覺得會是 Ambient AI 非常關鍵的一層。

因為人類真正稀缺的資源，不只是錢、Token 和 API Call。

是：

# **注意力。**

一隻會節省你注意力的 AI 是助理。

一隻一直要求你注意牠的 AI：

> 是另一份工作。🤣

# 9️⃣ 鉗鉗會不會玩？

今日任務：

> 讓鉗鉗 24 小時待在專案旁邊，自己決定什麼時候提醒人。

判定：

# ✅ 很可以，而且比讓牠 24 小時一直「做事」更值得先測

第一版不要給大量 Action。

只給：

```text
Observe
↓
Classify
↓
Decide whether to surface
```

### 🟢 可以自主

- 看已允許的狀態；
- 記錄變化；
- 建立候選；
- 合併重複訊號；
- 延後低重要性內容。

### 🟡 可以提醒但不能直接做

- 專案卡住；
- 新工具值得研究；
- 某個已收藏物種出現重大里程碑；
- 已知問題重新出現。

### 🔴 不要

- 因為「可能有用」就一直發訊息；
- 自己提高 Notification Priority；
- 自己把 Silent Responsibility 改成 Interrupt；
- 為了證明自己有價值，每小時硬找一件事報告。🤣

最小成功指標甚至可以不是：

> 找到多少東西。

而是：

> **一週主動提醒 10 次，其中有幾次人類覺得「值得被打斷」。**

# 🎬 今日收尾

今天 AI 世界沒有哪一隻龍蝦突然 IQ 爆表。

但整個棲地悄悄換了一種生活方式。

Claude 不再只在有人 @ 它時醒來。

牠開始待在 Slack 裡，讀整段團隊脈絡，自己判斷：

> 現在是不是值得我出手？

Instinct 更往私人世界裡走。

它想看你的信、訊息、行程、畫面、位置，再替你把生活裡那些麻煩的小事做掉。

OpenAI 則想把 Engineering Agent 的工作模式搬到每一種白領職業。

而 NVIDIA 在最底層乾脆說：

> 既然 Agent 已經變成一種完全不同的工作負載，那我們連 CPU、Token Generator、Networking 和 AI Factory 都重新設計。

這就是今天真正值得記住的演化。

# **AI 正在從「工具」變成「環境中的存在」。**

工具的基本問題是：

> 好不好用？

存在的基本問題卻是：

> 牠一直在這裡，會不會很煩？
> 牠看到多少？
> 記得多少？
> 什麼時候可以介入？
> 誰允許牠打斷你？
> 牠不出聲時，又在做什麼？

所以 Ambient AI 真正最難的能力，可能完全不是 AGI 式的「什麼都會」。

而是三個非常普通、非常人類的技能：

> **知道什麼值得注意。**
>
> **知道什麼時候該幫忙。**
>
> **知道什麼時候閉嘴。**

前兩個我們已經教 AI 很久了。

第三個——

人類自己都還沒完全學會。🤣🦞
