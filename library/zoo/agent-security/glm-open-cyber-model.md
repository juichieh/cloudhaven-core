# 🛡️ GLM Open Cyber Model

> 開放模型從商用模型拒答時的防守替代品，進一步演化成自身也需要能力分級、驗證存取與安全治理的高階資安物種。

## 🏷️ 分類

🛡 Open Cyber Model／能力分級開放模型

## ⭐ 收藏價值

★★★★★

## 🧬 和上次相比改變了什麼？

上一代 GLM‑5.2 最重要的圖鑑事件，是在 Agent 資安事故後被用來協助防禦分析，代表開放模型可在商用模型拒答時提供實際防守價值。

GLM‑5.3 再跨一步：

- CyberGym 公布分數已接近甚至略高於 Mythos 5；
- Exploit 能力仍明顯落後；
- Z.ai 正式提出 Trusted Access；
- 高風險能力將限制給驗證用戶；
- 公司同時啟動 Open Source Shield 計畫。

原本：

> 開放模型是商用模型拒答後的防守替代品。

今天變成：

> **開放模型自己也開始成為需要能力治理的高階資安物種。**

這意味著「開放」與「完全無分級」不再必然綁在一起。當模型能力跨越高風險門檻後，開放生態也開始面對驗證身份、分層授權與安全社群協作問題。

## 🎯 觀察重點

- Trusted Access 如何與開放權重／開放生態共存？
- 防禦能力與 Exploit 能力如何分開評估？
- 什麼能力門檻需要額外身份驗證或用途限制？
- Open Source Shield 類型的安全計畫能否形成開源社群共同防守能力？
- 開放模型治理是否會形成不同於封閉 API 的新模式？

## 🧬 Evolution Log

### GLM‑5.2｜開放模型成為防守替代品

在 Agent 資安事故後，GLM‑5.2 被用於防禦分析，凸顯開放模型在商用模型因政策拒答時的實務價值。

### 2026-08-15｜⭐ GLM‑5.3 能力治理里程碑

GLM‑5.3 的高階資安能力提升，同時出現 Trusted Access、高風險能力驗證用戶與 Open Source Shield，顯示開放模型本身也開始進入 Capability Governance 階段。
