# 🆕 Project Perception

> 由紅、藍、綠專門 Agent 組成，負責找漏洞、評估風險與產生修補方案的 Microsoft 資安平台。

────────────────

## 🏢 成熟度

────────────────

## ⭐ 收藏價值

★★★★★

────────────────

## 👍 為什麼收藏

它不是單一資安 Agent。

它代表的新物種是：

> 按照真人資安團隊職責拆分的 AI 防守組織。

紅隊負責尋找弱點，藍隊負責防禦與驗證，綠隊負責風險整理與修補建議。安全能力不再集中在一隻萬能 Agent，而是由具備不同職責、權限與檢查關係的 Agent 組織共同完成。

────────────────

## 🎯 觀察重點

- 紅、藍、綠 Agent 之間如何分工與互相驗證？
- 漏洞發現、風險評估與修補方案是否有清楚責任鏈？
- 是否能避免同一模型家族產生共同盲點？
- 人類資安團隊在何處批准、覆核與接管？
- 是否能與 MDASH、Patch Management 和企業稽核流程整合？
