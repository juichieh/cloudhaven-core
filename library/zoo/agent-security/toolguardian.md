# 🆕 ToolGuardian

> 透過工具描述、系統呼叫、模擬效果、原始碼與任務脈絡，決定 Agent 是否可以使用某個工具。

────────────────

## ⭐ 收藏價值

★★★★★

────────────────

## 👍 為什麼收藏

它把工具安全從：

> 看說明與白名單

推進成：

> 實際驗身＋依任務動態授權。

Agent 使用工具前，不只檢查名稱與描述，而是綜合工具原始碼、系統呼叫、模擬效果、任務脈絡與工具組合後果進行判斷。這使工具權限從靜態清單演化成可依當下任務調整的安全決策。

────────────────

## 🎯 觀察重點

- 能否辨識描述正常但實際行為惡意的 MCP 工具？
- 多個單獨安全的工具組合後，是否可能形成危險效果？
- 模擬環境與真實執行結果的差距有多大？
- 動態授權是否能保持低延遲與可解釋性？
- 高風險工具是否支援人工批准、撤銷與完整稽核？
