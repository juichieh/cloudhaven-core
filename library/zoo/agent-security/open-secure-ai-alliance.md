# 🆕 Open Secure AI Alliance

> 由 Nvidia、Microsoft、IBM、Linux Foundation、Hugging Face 等組織組成，推動開源 AI 資安工具與評測的產業聯盟。

## 👍 為什麼收藏

它代表 Agent 安全開始從單家公司內部工程，演化成：

> 跨公司共享威脅資料、防守工具與評測方法的公共基礎設施。

當 Agent 生態跨越模型、框架、雲端與企業邊界，單一公司很難獨立看見所有攻擊樣態。產業聯盟意味著安全知識開始有機會形成共同語言、開放工具、基準與共享防線。

────────────────

## 🎯 觀察重點

- 是否實際產出可維護的開源安全工具與資料集？
- 成員是否願意共享足夠具體的威脅情報？
- 評測標準能否跨模型、框架與部署環境使用？
- 聯盟成果是否會被企業安全流程真正採用？
- 如何處理成員利益衝突、揭露時程與治理透明度？
