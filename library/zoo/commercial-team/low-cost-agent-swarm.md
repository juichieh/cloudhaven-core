## 🧬 和上次相比改變了什麼？

低成本模型過去主要代表：

> 比較便宜的 API 替代品。

DeepSeek V4-Flash 將單次基準測試平均成本壓至約 0.03 美元，遠低於部分知名前沿模型，同時仍維持中階模型表現。

這使物種定位開始改變：

> 不是只問能不能用更便宜的模型，而是能不能因此養得起更多長時間工作的 Agent。

低成本不再只是採購優勢，也開始影響：

- Agent 數量；
- 任務分工粒度；
- 背景模擬頻率；
- 多居民世界的可負擔性；
- 模型路由與升級策略。

────────────────

## 🏠 鉗鉗生活觀察箱可用

- **一句話：** 讓非關鍵居民對話、排程與背景狀態更新交給低成本模型，主要角色互動時再升級模型。
- **為什麼用：** 符合觀察箱「居民平時用小模型，遇到鉗鉗等主要角色才切大模型」的既有設計。
- **可參考模組：** Resident Background Loop、Dialogue Routing、Model Escalation、Simulation Cost
- **採用狀態：** Observing；需要先驗證一致性與切換品質，不加入目前一日 Prototype 必要功能。

────────────────

## 🎯 觀察重點

- 低成本模型在長時間運作中是否容易人格漂移或重複？
- 小模型與前沿模型切換時，居民狀態是否保持連續？
- 便宜基準分數能否轉化為真實 Agent 任務可靠性？
- 大量 Agent 是否會因共同盲點而放大錯誤？
- 成本下降後，是否反而需要更強的監控、路由與治理？
