# 🌍 World as Agent Gym

> 用 MMORPG／持續世界測試 Agent 的長期規劃、社交與資源行為。

## 🏷️ 類型

Agent Evaluation / Living World

## ⭐ 收藏價值

⭐⭐⭐

## 為什麼收藏

一次性 benchmark 很擅長回答：

> Agent 這一題會不會做？

但真正長期自主 Agent 還需要被觀察：

- 是否能維持多日／多週目標；
- 是否會因短期利益破壞長期策略；
- 如何與其他 Agent 或真人建立合作與競爭關係；
- 如何管理稀缺資源、聲望、風險與機會成本；
- 世界狀態持續改變時，是否能重新規劃而不是重置任務。

MMORPG 或其他持續世界因此很像天然的 Agent Gym：環境不因單次測試結束而歸零，Agent 的歷史選擇會留下後果。

這比一次性 benchmark 更接近真實自主 Agent 所需能力；EVE 這類具有經濟、社交、風險與長期策略的世界，尤其值得持續觀察是否成為正式 AI 研究環境。

## 🎯 觀察重點

- 長期規劃能力能否跨越單一 session？
- Agent 是否會形成穩定社交策略與聲譽？
- 資源壓力會不會誘發投機、合作或背叛？
- 如何區分遊戲技巧、模型能力與 Harness 優勢？
- 世界是否能提供可重現、可量化又不失真實性的 Eval？
- Persistent World 是否能補足 oqoqo、Orchard 等較結構化 Eval 的盲區？
