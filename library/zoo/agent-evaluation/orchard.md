# 🧪 Orchard

> Microsoft 開源的可重用 Agent 訓練與測試環境框架。

## 🏷️ 類型

Agent Training / Evaluation Infrastructure

## ⭐ 收藏價值

⭐⭐⭐

## 為什麼收藏

Agent 生態正在從「把功能做出來」進入下一階段：

> 如何穩定、重複、可比較地驗證 Agent 到底能不能工作？

這類 infrastructure 的價值，不在於再增加一個 Agent 功能，而是讓 Agent、Model、Harness、Tools 或 Workflow 能在可重用環境裡被反覆訓練與測試。

對 AI Zoo 來說，這代表評估開始從一次性的 benchmark 或 demo，往更完整的 evaluation infrastructure 演化。

## 🎯 觀察重點

- 是否能建立可重用的 Agent 任務環境？
- 同一任務能否跨不同 Model / Harness 反覆測？
- 是否適合 long-running 或 multi-step Agent？
- 如何定義成功條件、失敗條件與回歸測試？
- 能不能與真實世界 Agent Evaluation、oqoqo 類工具形成互補？
- 是否有機會成為 Cloudhaven 日後驗證 Guidance、Workflow、Memory 或 Tool-use 行為的底層測試框架？

## 🧭 圖鑑定位

這不是新的 Agent 物種本身。

它更像是：

> **Agent 生態的訓練場＋考場基礎設施。**

如果 Agent 越來越像長期工作者，那麼「能不能穩定驗證牠」會跟「牠會多少功能」一樣重要。
