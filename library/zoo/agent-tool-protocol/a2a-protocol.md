# ⭐ A2A Protocol

> 跨平台 Agent 通訊標準，讓 Agent 能描述能力、交接任務、追蹤 Task Lifecycle，並逐步進入跨公司共享的中立治理體系。

## 🏷️ 分類

🗣 Agent-to-Agent Protocol／跨平台 Agent 通訊標準

## ⭐ 重大里程碑

A2A 之前已經具備：

- 150+ 組織支持；
- Google、Microsoft、AWS 等整合；
- Production Deployment；
- Agent Card；
- Task Lifecycle 等較成熟結構。

2026-08-17 的重要變化是：

> A2A 正式加入 Agentic AI Foundation，和 MCP 等核心 Agent 標準進入同一個中立治理體系。

這代表它不再只是 Google 發起的一套協定，而開始演化成：

> 跨公司共享的 Agent 公共基礎設施。

## 🎯 為什麼重要

Agent-to-Agent Communication 若要真正形成市場與社會，不能只靠同一家公司內部接口。

它需要：

- 可攜能力描述；
- 標準化任務交接；
- 狀態與生命週期；
- 中立治理；
- 能與 MCP、Registry、Eval 等其他基礎設施互補。

## 🔗 關聯

- MCP
- Agent Society
- Resident Discovery / Agent Discovery
- Agent Context Graph
- Agent Card

## 🦞 龍蝦一句話

「以前 Agent 會說話；現在開始有公共電話網路，而且不再只屬於某一家電信公司。」
