# ⭐ MCP / Model Context Protocol

> 從「Agent 插頭標準」進化成可承載大量生產級 Agent 工作的通用基礎設施。

## 🏷️ 分類

🔌 Agent Tool Protocol／Agent Internet Infrastructure

## ⭐ 收藏價值

★★★★★

## 🧬 和上次相比改變了什麼？

MCP 過去在圖鑑中的核心定位主要是：

> 讓 Agent 標準化連接工具。

2026-07-28 規格後，能力版圖明顯擴張，加入或正式化：

- Stateless Core
- 普通 HTTP 水平擴展
- Header Routing
- Cache
- W3C Trace
- Tasks
- MCP Apps
- Enterprise Authorization
- Extensions Framework
- 正式 Deprecation Policy

同時 Tier 1 SDK 已接近每月 5 億次下載。

因此 MCP 的定位已經從：

> Agent 插頭標準

進化成：

> 可承載大量生產級 Agent 工作的通用基礎設施。

## 🎯 觀察重點

- Tool connection 是否逐漸變成 Agent infrastructure 的共同底層？
- Tasks / Apps 是否讓 MCP 從「呼叫工具」進一步承載工作流程？
- Enterprise Authorization 是否能支撐真實組織的權限治理？
- W3C Trace 與水平擴展是否讓 observability / production scale 成為標準能力？
- Extensions Framework 是否會形成新的 Agent internet extension ecosystem？

## 🧬 Evolution Log

### 2026-08-13｜⭐ 從插頭標準進化成 Agent Internet Infrastructure

MCP 不再只是標準化 tool calling，而開始具備任務、應用、企業授權、追蹤、水平擴展與擴充框架等生產環境能力。

## 🦞 龍蝦一句話

「以前是幫 Agent 做插座；現在開始像在鋪整座 AI 城市的水電管線。」
