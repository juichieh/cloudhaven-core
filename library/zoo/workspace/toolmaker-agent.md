# 🆕 Toolmaker Agent

> Agent 不只完成任務，而是把重複工作製造成下一次可直接使用的 App 或 Workflow。

## 🏷️ 分類

🔨 Meta-Automation／AI 製造工作流程

## 🌱 成熟度

已在 Cloudflare OS 等企業 Agent 系統實際出現。

## ⭐ 收藏價值

★★★★★

## 👍 為什麼收藏

Agent 生產力開始從：

> 做更多工作

變成：

> 降低未來完成同樣工作的推理成本。

AI 不只累積 Knowledge，還開始累積 Operational Capability。

這意味著 Agent 每完成一次工作，都可能把流程固化成可重複使用的技能、App、模板或工作流。

## 🎯 觀察重點

- 何時應把一次性推理固化成可重複流程？
- 新生成的 Workflow 如何測試、版本化與批准？
- 是否會產生錯誤流程被大量重複的風險？
- Operational Capability 是否能與模型分離、跟著居民或組織保留？
- Cloudhaven 能否把常做任務慢慢沉澱成鉗鉗自己的技能庫？

## 🧬 Evolution Log

### 2026-08-08｜🆕 新發現

首次收錄為 Meta-Automation 類新物種：Agent 從執行既有流程，進一步成為製造下一代流程與工具的角色。
