# 🆕 Cloudflare OS

> 把組織知識、Skills、Agent Workspace、安全政策、Apps、模型與內部系統整合成同一個開源 AI 工作平台。

## 🏷️ 分類

🏢 Agent-native Organization／企業 AI 作業系統

## 🟢 成熟度

Cloudflare 已內部大規模使用，開源版本正式公開。

## ⭐ 收藏價值

★★★★★

## 👍 為什麼收藏

它不是再一個企業 Chatbot。

它代表的新物種是：

> 公司本身成為 Agent 可以生活的 Runtime。

特別值得 Cloudhaven 觀察的是：

- 公司知識與 Skills 不綁死在某顆模型上；
- 模型可以替換；
- 組織累積的能力與工作方式留下來；
- Workspace、Policy、Apps、Knowledge 能作為持續層存在。

這與 Cloudhaven 的 Resident／Memory／Skill 分離非常接近。

## 🎯 觀察重點

- Knowledge、Skill、Model、Identity 是否真的能解耦？
- 模型替換後，組織能力與工作脈絡能否完整延續？
- Workspace 如何處理長時間 Agent、權限與多人協作？
- Skills 如何被版本化、批准與撤銷？
- 是否能作為 Cloudhaven Resident Runtime 的企業級參考？

## 🧬 Evolution Log

### 2026-08-08｜🆕 新發現

首次收錄為 Agent-native Organization 類新物種：不是把 Agent 塞進既有公司軟體，而是把整個組織工作環境設計成 Agent 可持續存在與工作的 Runtime。

## 🦞 龍蝦一句話

「以前公司買 AI 工具；現在開始把整家公司改造成 AI 能住進去的作業系統。」
