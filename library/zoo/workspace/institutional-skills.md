# Shared Skills / Institutional Skills

## Classification

🧬 Institutional Skills / Agent Skill Library

## Current Evolution

上一期 Cloudflare OS 讓我們看到：

> Agent 可以把重複經驗沉澱成整個組織共享的 Skill。

Prime Agent / Continual Harness 再推進一層：

> Skill 本身可以由 Agent 在執行過程持續演化，甚至連 Prompt、Subagent、Harness 都成為改善對象。

因此這個物種從：

人類建立 Skill
→ AI 使用

演化成：

AI 使用 Skill
→ 發現不足
→ 建立改進候選
→ 外部 Eval / Human Review
→ 下一版 Skill

## Why It Matters

真正成熟的 Agent 組織不只累積 Knowledge，也會累積 Operational Capability。

重複任務不應每次都重新規劃；更多時候應該讓既有 Workflow / Skill 變強。

這可以降低：

- 重複推理
- Token 成本
- 行為漂移
- 新 Workflow 無限增生

## Governance Boundary

可演化 Skill 必須與不可自行修改的 Goal、Eval、Permission、Approval、Audit 邊界分離。

原則：

> 可以讓 Agent 改進方法，但不能讓它自己改寫成功標準。

## Cloudhaven Relevance

與 Guidance Layer / Learned Workflow 高度相關：

Task
→ Guidance
→ Reuse / Adapt Skill
→ Execute
→ Eval
→ Improve Existing Skill / Create New Skill / No Save
