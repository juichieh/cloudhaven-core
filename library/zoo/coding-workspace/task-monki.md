# 🆕 Task Monki

> 讓多隻 Coding Agent 從任務、實作、互相審查一路工作到 Pull Request 的開源桌面應用。

────────────────

## 🏷️ 分類

🐒 多 Coding Agent 開發工作台／Agent 協作管理

────────────────

## 🌱 成熟度

────────────────

## ⭐ 收藏價值

★★★★☆

────────────────

## 👍 為什麼收藏

它不是另一隻 Coding Agent。

它代表新的物種：

> 專門管理、觀察與協調多隻 Coding Agent 完成完整開發流程的桌面工作台。

重點不只是叫多隻 Agent 同時工作，而是把任務拆分、實作、互審與 Pull Request 串成一套可觀察流程。

────────────────

## 🎯 觀察重點

- 多 Agent 是否真的能降低開發時間，而不是增加協調成本？
- Agent 互審能否抓出實質問題，而不是彼此附和？
- 任務狀態、責任與失敗原因是否清楚可追蹤？
- 是否能接入既有 GitHub、CI 與人工審查流程？
- 是否適合作為鉗鉗未來多 Agent 開發駕駛艙的參考？
