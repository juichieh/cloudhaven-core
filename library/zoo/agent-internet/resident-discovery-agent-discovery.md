# 🚦 Resident Discovery / Agent Discovery

> 根據 Agent Card、真實 Eval、成本、權限與近期表現，自動找到最適合完成某項工作的 Agent。

## 🏷️ 分類

🚦 Agent Selection／能力型服務發現

## 🧪 成熟度

🌱 協定與研究元件已逐漸齊全，完整市場仍早期。

## ⭐ 收藏價值

★★★★★

## 為什麼收藏

Agent 世界不可能永遠靠：

> 每個人手動知道每隻 Agent。

當 Agent 數量成長到幾千、幾萬，真正重要的新能力會變成：

> Finding intelligence，而不只是 building intelligence。

也就是說，系統不只要會建立 Agent，也要會根據：

- Agent Card；
- 真實 Eval；
- 成本；
- 權限；
- 近期表現；
- 可用性；
- 任務風險；

找到此刻真正適合執行任務的對象。

## 🎯 觀察重點

- Discovery 是否依賴靜態能力描述，還是實際 Eval？
- 如何處理最新表現與過去聲譽？
- 成本與品質如何平衡？
- 權限與安全邊界是否進入選擇條件？
- Agent Registry 如何避免被過度自我宣傳或錯誤 metadata 污染？
- 是否需要 Human Approval 才能切換高權限 Agent？
