# 🌐 Machine Citizen / Agent Web Traffic

> 代表人類或系統自主瀏覽、搜尋、比較與操作網站的 AI Agent 流量，開始成為可獨立測量的 Web 流量類型。

## 🏷️ 分類

🌐 Agent Internet／非人類網路居民

## 🟢 成熟度

🟢 已在真實網路大量出現。

## ⭐ 收藏價值

★★★★☆

## 為什麼收藏

Agent Internet 不再只是未來架構。

HUMAN Security 的資料顯示，Agentic AI／Agentic Browser 流量在一年內增長 7,851%。

這代表網站開始面對一種新的訪客：

> 不是傳統 Bot，也不完全是人類，而是代表人類或系統自主完成搜尋、比較與操作的 Agent。

牠們已經：

> **真的在路上。**

這會改變網站設計、身份判斷、流量分析、授權、反濫用與 Agent UX。

## 🎯 觀察重點

- Agent traffic 如何與傳統 bot、crawler、人類流量區分？
- 網站是否需要提供更適合 Agent 的結構化上下文？
- 如何辨識合法代理與惡意自動化？
- Agent 代表人類操作網站時，身份、授權與責任如何傳遞？
- Web analytics 是否需要獨立的 Agent traffic 指標？
- Agent-ready Website 是否會從 UX 選項變成基礎 Web 能力？
