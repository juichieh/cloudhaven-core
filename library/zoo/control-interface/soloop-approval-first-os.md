# 🆕 Soloop Approval-first OS

> AI 每次只提出一個最值得做的下一步，由人批准後才派 Research、Social 或 Coding Agent 執行。

## 🏷️ 分類

🛂 Human-Agent Decision UX／Approval-first Agent OS

## 🌱 成熟度

新推出。

## ⭐ 收藏價值

★★★★☆

## 👍 為什麼收藏

它不是新的 Agent 能力。

而是一種新的 Agent 管理哲學：

> 不要叫人類管理 Agent，只讓人類管理決策。

當 Agent 數量增加，人類若必須逐隻監工，UX 很快會崩潰。Soloop 的價值在於把複雜度藏在後面，只把真正需要人類判斷的下一步送到前台。

## 🎯 觀察重點

- 如何挑出「唯一最值得批准的下一步」？
- 人類是否能看懂理由、成本、風險與預期結果？
- 批准的是決策，還是模糊授權整串後續行動？
- 多 Agent 執行後如何回報結果與重新升級？
- 是否適合作為鉗鉗觀察箱的 Human Approval UX 參考？
