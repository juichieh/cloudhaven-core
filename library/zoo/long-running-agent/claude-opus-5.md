> 從能完成長任務的 Agent，進化成會在任務中自我檢查、維護工作記憶，並依用途取得不同能力執照的 Agent。

## 🧬 和上次相比改變了什麼？

Claude 的 Agent 物種原本已具備程式操作、工具使用與長任務能力。

Opus 5 這次的重要變化是：

- 更能持續處理模糊、長時間工作；
- 會自行建立測試方法；
- 更常找根本原因並驗證成果；
- 部分監控 Agent 已能修正自己的記憶與停止無效查詢；
- 高風險資安能力開始搭配驗證身分的分級開放制度。

原本是：

> 能完成長任務的 Agent。

今天進化成：

> 會在任務中自我檢查、維護工作記憶，並依用途取得不同能力執照的 Agent。

────────────────

## 🎯 觀察重點

- 自建測試是否能有效避免「完成了，但其實做錯」？
- 工作記憶修正會不會誤刪重要上下文？
- 無效查詢停止機制是否能降低長任務成本？
- 高風險能力分級制度是否透明、可稽核且可撤銷？
- 身分驗證與用途限制能否真正降低資安濫用？
