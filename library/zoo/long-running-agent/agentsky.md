# 🆕 AgentSky

> 讓不同 Agent Harness 與模型一鍵部署成長時間在線、可保存狀態並跨通訊平台工作的雲端 Agent。

────────────────

## ⭐ 收藏價值

★★★★★

────────────────

## 👍 為什麼收藏

它不是單純 Hosting。

它把 Agent 拆成：

- 可替換的大腦；
- 可保存的生命狀態；
- 可跨不同通訊入口出現的居民。

這和 Cloudhaven 的 Resident Passport、模型可替換與長期居民路線非常接近。

────────────────

## 🎯 觀察重點

- Resident state 與模型、Harness、通訊平台是否真正解耦？
- 快照與恢復是否會造成外部副作用重複？
- 權限、憑證與記憶能否隨居民安全遷移？
- 更換模型後，居民身分與行為連續性如何驗證？
- 成本、可靠性與長時間在線品質是否足以支撐生活型 Agent？

────────────────
