# 🧠 Long-running Agent／長時間工作 Agent

> 觀察 Agent 如何在模糊、多步驟與長時間任務中維持目標、驗證成果、管理工作記憶並知道何時停止或升級給人類。

────────────────

## 🏷️ 分類定位

Long-running Agent / Self-verifying Agent / Working Memory Governance

這類卡片主要觀察：

- 長任務中的目標維持與進度追蹤
- 自行建立測試、驗證與停止條件
- 工作記憶的修正、清理與來源治理
- 無效查詢、循環與資源浪費的抑制
- 高風險能力的分級授權與身分驗證

────────────────

## 🧭 適合收錄

- Long-horizon Agent
- Self-verifying Agent
- Research Agent
- Coding Agent
- Working Memory Management
- Capability Licensing
