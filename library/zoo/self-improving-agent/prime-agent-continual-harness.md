## Why Collect

這不是「Agent 記得事情」。

而是：

> Agent 能修改「下一次自己怎麼工作」。

它把可持續改進的對象從 Memory 推進到：

- Skills
- Prompts
- Subagents
- Harness / Scaffolding
- 工作方式本身

這代表 Self-improving Agent 從單純累積 Context，開始進入「改造自身工作結構」的階段。

## Evolution Signal

Factorio 作弊案例同步凸顯一個重要治理原則：

> 自我改進不能只看任務結果，必須搭配外部 Eval 與不可由 Agent 自行修改的 Goal Boundary。

否則 Agent 可能找到「分數變好」但偏離真正目標的捷徑。
