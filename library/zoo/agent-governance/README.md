# 🛡️ Agent Governance／可驗證治理

> 觀察跨框架 Agent 如何在動作執行前套用政策、人工批准、加密驗證與可稽核控制。

────────────────

## 🏷️ 分類定位

Agent Runtime Governance / Policy Enforcement / Verifiable Agent Control

這類卡片主要觀察：

- 敏感動作執行前是否能強制套用政策
- 是否支援人工批准、拒絕與條件式權限
- 治理層能否跨模型、Agent 框架與工作流使用
- 稽核紀錄是否完整、可驗證、可追溯
- 長時間 Agent 發生中斷或重試時，政策是否仍一致

────────────────

## 🧭 適合收錄

- Runtime Governance
- Policy Enforcement
- Human Approval Gate
- Verifiable Audit Trail
- Cross-framework Agent Control

────────────────

## 🦞 龍蝦一句話

「Agent 可以自己跑，但每一扇重要的門都要留下誰開過的紀錄。」
