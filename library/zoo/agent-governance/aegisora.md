# 🆕 Aegisora

> 位於 Agent 與工具之間，攔截危險呼叫、縮小 API 權限、遮蔽敏感資料並保存稽核軌跡的開源代理層。

## 👍 為什麼收藏

它代表安全從：

> 期待 Agent 自己遵守規則

進化成：

> 每一個真實動作都必須通過獨立執法層。

這讓政策不再只是提示詞或文件，而能在工具呼叫真正發生前被攔截、縮權、遮蔽與記錄。

────────────────

## 🎯 觀察重點

- 是否能在工具呼叫前可靠攔截，而不是事後記錄？
- API 權限能否依單一任務縮小到最小範圍？
- 敏感資料遮蔽是否會破壞任務所需資訊？
- 多工具組合時是否能追蹤間接風險？
- 人工批准、稽核與撤銷是否足以支援長時間 Agent？
- 是否能與 ToolGuardian、OpenBox、Prefactor 串成完整治理層？

────────────────
