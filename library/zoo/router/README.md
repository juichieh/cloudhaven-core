# 🚦 Router／多 Agent 路由與執行基礎設施

> 觀察 Agent 如何像運算資源一樣被挑選、替換、沙盒化與動態調度。

────────────────

## 🏷️ 分類定位

Multi-Agent Router / Agent Execution Infrastructure / Dynamic Agent Dispatch

這類卡片主要觀察：

- 是否能透過單一 API 調用多種 Agent
- Agent 能否依任務、成本、速度與可靠性動態選擇
- 執行環境是否隔離、可稽核、可替換
- 失敗時是否能切換模型、Agent 或沙盒

────────────────

## 🧭 適合收錄

- Multi-Agent Router
- Agent Dispatch Layer
- Sandboxed Coding Agent API
- Cost-aware Agent Routing
- Agent Execution Fabric

────────────────
