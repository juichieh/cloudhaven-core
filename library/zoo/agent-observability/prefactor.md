# 🆕 Prefactor

> 在每次 Agent 正式執行時，即時評估品質、風險與漂移，並直接觸發後續處置的監控層。

────────────────

## 🏷️ 分類

📡 Agent 生產環境即時評測／行為漂移監控

────────────────

## 🌱 成熟度

🌱 已推出，面向正在部署 Agent 的開發團隊。

────────────────

## ⭐ 收藏價值

★★★★★

────────────────

## 👍 為什麼收藏

它不是一般日誌平台。

它代表 Agent 品質管理從：

> 上線前通過測試。

進化成：

> 每次執行都是一次新的評測。

當 Agent 會接觸不同使用者、資料與工具時，單次測試通過並不能保證未來每次執行都安全可靠；生產環境本身必須成為持續評測場。

────────────────

## 🎯 Cloudhaven 用途

- 監控鉗鉗長時間任務的品質與異常行為；
- 發現模型更新、工具變更或記憶污染造成的行為漂移；
- 依風險自動觸發人工審核、暫停或回滾；
- 為每次重要執行留下可比較的品質與安全紀錄。
