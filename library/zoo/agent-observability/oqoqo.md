## Collection Value

## Why Collect

它不是測：

> 模型懂不懂題目。

而是測：

> Agent 能不能在你的世界裡正常生活。

這類 Eval 更接近真實 Agent 系統需要回答的問題：

- 工具有沒有真的用對
- 任務有沒有真的完成
- Harness 是否穩定
- 不同模型換上去後是否仍能工作
- 成功條件是否能在真實環境被驗證

## Evolution Signal

Agent 評估正在從靜態問答 benchmark，走向：

Prompt Score
→ Tool Task
→ Real-world Workflow
→ Environment-specific Success Criteria

對 AI Zoo 而言，這種分數比單純模型排行榜更接近「這隻動物能不能活」。

## Cloudhaven Relevance

非常適合未來拿來驗證：

- Guidance Layer
- Learned Workflow
- Tool routing
- Resident behavior
- Model replacement
- Harness stability

重點不是找最高分模型，而是建立「Cloudhaven 自己的真實生活任務集」。
