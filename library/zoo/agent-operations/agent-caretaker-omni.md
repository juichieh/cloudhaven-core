# 🧑‍🔧 Agent Caretaker / Omni

> 專門替其他 Agent 接工具、測試、部署、監控、除錯並優化工作方式的 AI Agent。

## 🏷️ 分類

🧑‍🔧 Agent Operations／Agent 維運工程師

## 🧪 成熟度

🌱 已推出的早期產品。

## ⭐ 收藏價值

★★★★★

## 為什麼收藏

以前常見的是：

> Agent 做人的工作。

這個新物種的工作對象變成：

> 其他 Agent。

代表 Agent 世界開始形成第二級產業：

Worker Agent
↓
需要
↓
Agent Infrastructure
＋
Agent Operations
＋
Agent Maintenance

真正值得觀察的是，Agent 生態開始需要「維運角色」，不再只是需要更多 Worker。

## 🎯 觀察重點

- 能否替其他 Agent 自動接入工具？
- 測試與部署是否能形成可重複流程？
- 監控與除錯能否跨模型、跨 Harness？
- 最佳化是否會修改 Prompt、Skill、Tooling 或 Workflow？
- 如何避免 Caretaker 自己成為高權限單點風險？
