# Muse Glimmer

## Classification

🏠 Always-on Local Agent / 個人本地居民模型

## One-line Summary

Meta 的 30B 開放權重模型，專門針對本地、長時間 Agent、工具使用、失敗恢復與個人 Context 設計。

## Maturity

🟢 模型已發布，周邊整合持續推出。

## Collection Value

★★★★★

## Why Collect

Local Model 過去多半被定位成：

- 隱私
- 便宜
- 離線

Muse Glimmer 把定位明確推向：

> 一隻一直住在使用者設備裡、持續處理個人生活 Context 的 Agent。

這使 Local AI 從「本地執行模型」演化成「長期駐留的 Personal Agent」。

## Evolution Signal

值得觀察的不是單次 benchmark，而是：

- Always-on
- Long-running context
- Tool use
- Failure recovery
- Personal context continuity
- Local-first privacy boundary

## Cloudhaven Relevance

與 Cloudhaven / 鉗鉗生活觀察箱的 Resident Model 很接近：

- Model 可替換
- 個人 Context 長期存在
- 本地居民長時間運作
- 隱私與低成本具有優勢

但是否採用仍取決於實際硬體需求、長時間穩定性、工具生態與治理能力。
