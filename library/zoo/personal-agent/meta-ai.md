# 🧬 Meta AI／Personal Agent

> 從社群與創作助手，逐步演化成掌握信件、日程、持續任務與長期人生目標的消費型生活 Agent。

🧑‍💼 個人生活 Agent／跨服務幕僚

★★★★★

## 🧬 和上次相比改變了什麼？

### 第一階段｜2026-07-25

Meta AI 從聊天、搜尋、創作與社群互動型助手，開始：

- 連接 Gmail 與 Google Calendar；
- 建立每日簡報；
- 處理重複任務；
- 做較長的研究與規劃；
- 依照個人日常上下文執行工作。

定位從：

> 社群平台裡的 AI 助手

演化成：

> 開始掌握日程、信件與持續任務的個人幕僚。

### 第二階段｜2026-07-30

產品方向進一步被明確描述為：

- 24 小時替人工作；
- 協助健康、財務、關係等長期人生目標；
- 成為未來產品與營收的基礎；
- 面向數十億普通使用者，而不只是技術族群。

定位因此再次演化：

> 能讀取日程與執行任務的個人幕僚

進一步成為：

> 長期介入人生目標、持續調整使用者行為的消費型生活 Agent。

────────────────

## ⚠️ Cloudhaven 信任警戒

這張卡的收藏價值很高，但不代表適合接入 Cloudhaven。

目前採用判定：

```text
rejected
```

原因：

- Gmail、Calendar、健康、財務與關係資料高度敏感；
- 長期生活 Agent 不只讀資料，也可能逐步影響使用者選擇與行為；
- 個人資料集中到單一商業平台後，權限、刪除、用途變更與跨境資料治理風險會放大；
- 對平台信譽與資料合作網絡缺乏足夠信任；
- Cloudhaven 核心生活資料應優先交給信任度較高、資料邊界清楚且可撤回的系統。

因此本卡定位為：

> 高價值物種觀察，低信任採用候選。

────────────────

## 🎯 觀察重點

- Gmail 與 Calendar 權限是否細緻、可撤銷且可稽核？
- 健康、財務、關係等長期目標資料如何保存與使用？
- 每日簡報是否真正理解優先級，而非重新排列通知？
- 重複任務能否跨天穩定延續？
- 個人上下文是否透明、可編輯、可刪除、可匯出？
- 使用者是否能知道 Agent 正在如何影響自己的決策與行為？
- 商業營收目標是否會與使用者長期利益發生衝突？

同日加入 Cloudhaven 信任警戒：物種價值高，但因個資、平台信任與長期行為介入風險，採用狀態維持 rejected。
