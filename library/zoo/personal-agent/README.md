# 🧑‍💼 Personal Agent／個人生活 Agent

> 觀察 AI 如何從聊天助手，演化成掌握信件、日程、研究、規劃與持續任務的跨服務個人幕僚。

────────────────

## 🏷️ 分類定位

Personal Agent / Cross-service Chief of Staff / Life Operations Agent

這類卡片主要觀察：

- 是否能連接 Email、Calendar 與其他日常服務
- 是否能建立每日簡報與持續追蹤任務
- 是否能根據個人上下文主動規劃與執行
- 權限、隱私與錯誤修正是否足以支撐生活型任務
- 是否能從有限功能走向真正的長期幕僚

────────────────

## 🧭 適合收錄

- Personal Agent
- Life Assistant
- Cross-service Chief of Staff
- Daily Briefing Agent
- Personal Workflow Agent
