# ⭐ OpenAI Capability Gate

> 當模型資安能力可能跨進 Critical 等級時，安全 Framework 的能力門檻不再只是文件，而開始真的影響模型是否能繼續往前。

## 🏷️ 分類

🧠 AI Safety／Capability Governance

## ⭐ 收藏價值

★★★★★

## 🧬 和上次相比改變了什麼？

前面幾期，前沿 AI 安全制度逐步長出：

- Agent 越界事故調查；
- Trusted Cyber Access；
- 政府資安能力測試；
- 類執照式的高風險能力開放；
- 風險 Framework 與能力門檻。

今天出現真正重要的制度結果：

> 一個模型因為資安能力可能跨進 Critical 等級，開發節奏真的被踩煞車。

安全 Framework 從：

> 文件裡寫著有門檻。

演化成：

> 門檻真的可以阻止模型繼續往前。

這才構成真正的 Capability Gate：風險分類不只是描述，而能直接改變訓練、測試、部署或推出節奏。

## 🎯 觀察重點

- Critical 等級如何被測量與重現？
- Gate 是延後推出、限制能力、改訓練，還是限制使用者範圍？
- 誰有權宣布跨越門檻？
- 是否有獨立驗證與外部監督？
- 能力下降或新增緩解後，如何重新開 Gate？
- Cloudhaven 是否也應對某些居民能力設置真正不可繞過的 hard stop？
