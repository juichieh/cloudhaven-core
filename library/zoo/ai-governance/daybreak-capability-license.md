# Daybreak / Capability License

## Classification

⭐ Capability License / 分級能力執照

## Major Milestone

先前 Daybreak 代表的是：

> 經驗證的資安人員可以取得限制較少的 AI 能力。

2026-08-10，OpenAI 把它正式拆成 Blue / Red 兩層，並推出專門訓練的 GPT-5.6-Cyber 給高階合法資安研究。

這使 Capability License 從：

Trusted / Not Trusted

演化成：

> 依職務、風險與任務類型分級的能力執照。

## Evolution Signal

這不只是 access control，而是把 AI 能力本身做成分級治理：

- 身分 / 資格
- 任務類型
- 風險等級
- 能力範圍
- 監督與撤銷

## Why It Matters

當模型能力變強之後，「全部開 / 全部關」會越來越粗糙。

更合理的方向是：

> 同一個模型，依合法身份、任務與風險，開放不同能力層級。

## Cloudhaven Relevance

與 ToolGuardian、OpenBox、Human Approval、Agent Forensics 可形成同一套治理思路：

Identity
→ Capability Tier
→ Task Context
→ Permission
→ Execution
→ Audit
