# 🆕 Buzz

> 讓人類、Agent、對話與程式碼以第一級成員身分共同工作的開源、可自主託管工作空間。

## 👍 為什麼收藏

它不是 Slack 裡多一隻 Bot。

它提出的是新的組織單位：

> 人類與 Agent 使用同一套身分、對話與專案脈絡共同工作。

這使 Agent 從附屬工具進一步變成工作空間中的正式成員，開始共享長期上下文、程式碼、任務與組織責任。

────────────────

## 🎯 觀察重點

- 人類與 Agent 的身分、權限與責任是否真正對等可治理？
- 對話、程式碼與專案上下文能否長期保持一致？
- 自主託管是否真的降低資料與供應商風險？
- 多 Agent 協作時如何避免重複工作與上下文污染？
- 是否能形成可稽核的組織工作紀錄？
