# 💬 Human-Agent Workspace／人類與 Agent 協作工作空間

> 觀察人類、Agent、對話、程式碼與專案脈絡如何在同一個工作空間中成為第一級成員。

────────────────

## 🏷️ 分類定位

Human-Agent Workspace / Shared Organizational Context / Agent Collaboration Society

這類卡片主要觀察：

- 人類與 Agent 是否使用同一套身分與專案脈絡
- Agent 是否只是外掛 Bot，還是正式組織成員
- 對話、程式碼、任務與權限能否持續共用
- 是否支援自主託管、可攜性與組織治理

────────────────

## 🧭 適合收錄

- Human-Agent Workspace
- Agent Collaboration Platform
- Shared Project Context
- Self-hosted Agent Team Space
- Human-Agent Organization Layer

────────────────

## 🦞 龍蝦一句話

「不是把 Bot 拉進群組，而是讓人類和 Agent 一起進公司。」
