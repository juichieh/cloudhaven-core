## 🧬 和上次相比改變了什麼？

### 第一階段：記憶成為跨時間攻擊面

前期主要觀察：

- 跨 App
- 跨模型
- 跟著居民搬家
- 形成持續身分

GhostWriter 顯示，惡意內容可以先潛伏在記憶中，再由未來任務喚醒；Agent Data Injection 則提醒，外部假資料可能繞過只針對惡意「指令」設計的防線。

原本這個物種是：

> 記得越多，越像長期同伴。

後來演化成：

> 記得越久，越需要知道每段記憶從哪裡來。

### 第二階段：記憶成為模型之外的獨立基礎設施

先前已有 Memmy、Unabyss 等工具，證明記憶開始脫離單一 App。

Atlaso 的出現讓這個物種更清楚地形成一個獨立產品類別：

- 一次連接多個 AI 工具；
- 跨 Codex、Claude Code、Cursor、ChatGPT 使用；
- 保存專案、決策與工作偏好；
- 讓模型可以替換，脈絡仍留在使用者身邊。

原本是：

> 某隻 AI 記得你。

今天進化成：

> 記憶成為多隻 AI 共用、獨立於模型之外的個人基礎設施。

## 🎯 治理要求

- 每段記憶的來源、時間戳與寫入者
- 信任等級與寫入／讀取權限
- 使用前重新驗證
- 隔離、刪除、回滾與稽核
- 外部資料與內部記憶的邊界
- 跨 App 同步時的污染傳播控制
- 匯出、遷移與永久刪除能力
- 多模型同時修改時的衝突處理
- 使用者能否保留記憶，不被單一模型公司鎖定
