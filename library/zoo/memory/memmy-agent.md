# 🆕 Memmy Agent

> 讓 Codex、Claude Code、OpenClaw、Hermes 等不同 Agent，共享同一位使用者的偏好、決策、進度與經驗。

────────────────

## 🏷️ 分類

🧠 跨模型共享居民記憶／本地個人記憶中樞

────────────────

## 🌱 成熟度

🌱 已推出的本地優先產品。

────────────────

## ⭐ 收藏價值

★★★★★

────────────────

## 👍 為什麼收藏

它不是替單一聊天工具增加記憶。

它提出的是：

> 記憶屬於使用者與角色，不屬於某一家公司或某一隻模型。

這與 Cloudhaven 的澄丸、Resident Passport 與模型可替換設計幾乎完全同路。

────────────────

## 🎯 Cloudhaven 用途

- 讓鉗鉗、小澄澄與其他工作 Agent 共享同一套使用者偏好與專案進度；
- 把居民記憶與模型供應商解耦；
- 支援本地保存、可遷移、可刪除與可稽核的長期記憶；
- 作為澄丸與 Resident Passport 的產品參考；
- 降低模型切換時角色失憶或人格斷裂的風險。

────────────────

## ⚠️ 觀察重點

- 記憶來源、時間與寫入者是否可追溯？
- 不同 Agent 寫入衝突時如何合併與回滾？
- 本地優先是否真的包含加密、備份與完整刪除？
- 敏感記憶能否按角色、工具與任務分級授權？
- 是否能避免 GhostWriter 類長期記憶污染？
