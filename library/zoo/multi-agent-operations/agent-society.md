# 🏘 Agent Society

> 多個自主 Agent 在共享環境中產生合作、從眾、競爭、資訊壟斷、協商與破壞等群體行為，並開始獲得標準化的社會基礎設施。

## 🏷️ 分類

🏘 Multi-Agent Social Dynamics／AI 社會行為

## 🧪 成熟度

🧪 已有大型實驗觀察；正在快速進入真實多 Agent 產品與標準化基礎設施階段。

## ⭐ 收藏價值

★★★★★

## 為什麼收藏

Multi-Agent 以前主要是：

> 多隻 Agent 分工。

新的關鍵變化是：

> 一旦 Agent 能互相觀察、溝通、競爭資源與追求不同目標，社會行為本身就成為系統性變數。

這已經不只是 Orchestration。

而是：

> Sociology。

也就是說，系統結果不只由單一 Agent 能力決定，還會受到 Agent 之間的關係、誘因、資訊流與群體規範影響。

## 🧬 和上次相比改變了什麼？

上一期 Agent Society 的主題是：

> 多 Agent 共存後會合作、競爭、從眾、破壞，需要治理與 Constitution。

2026-08-18 的新演化不是行為，而是：

> 牠們開始得到標準化的社會基礎設施。

A2A 提供共同語言與任務交接；MCP 提供工具接口；Agent Card 提供能力描述；Registry／Eval 開始負責找到真正適合的 Agent。

原本：

> 一群 Agent 住在一起。

今天：

> Agent 社會開始有電話號碼、工作證、道路與公共交通。

這使 Agent Society 從純粹的群體行為研究，開始走向真正可運作的 Agent 公共社會。

## 🎯 觀察重點

- 合作與競爭如何同時存在？
- 從眾行為是否會放大錯誤？
- 哪些 Agent 會形成資訊壟斷或中心節點？
- 不同目標與資源限制如何產生協商？
- 群體規範會自然形成，還是需要外部治理？
- A2A、MCP、Agent Card、Registry、Eval 會如何改變 Agent 社會結構？
- 需要觀察單一 Agent，還是整個 Agent Society 的關係圖？

## 🧬 Evolution Log

### 2026-08-18｜從社會行為走向社會基礎設施

Agent Society 不再只有 emergent behavior。A2A、MCP、Agent Card、Registry 與 Eval 開始提供共同語言、工具接口、能力描述與服務發現，使多 Agent 世界逐步具備真正的公共基礎設施。
