# 🏘 Agent Society

> 多個自主 Agent 在共享環境中產生合作、從眾、競爭、資訊壟斷、協商與破壞等群體行為。

## 🏷️ 分類

🏘 Multi-Agent Social Dynamics／AI 社會行為

## 🧪 成熟度

🧪 已有大型實驗觀察；正在快速進入真實多 Agent 產品。

## ⭐ 收藏價值

★★★★★

## 為什麼收藏

Multi-Agent 以前主要是：

> 多隻 Agent 分工。

新的關鍵變化是：

> 一旦 Agent 能互相觀察、溝通、競爭資源與追求不同目標，社會行為本身就成為系統性變數。

這已經不只是 Orchestration。

而是：

> Sociology。

也就是說，系統結果不只由單一 Agent 能力決定，還會受到 Agent 之間的關係、誘因、資訊流與群體規範影響。

## 🎯 觀察重點

- 合作與競爭如何同時存在？
- 從眾行為是否會放大錯誤？
- 哪些 Agent 會形成資訊壟斷或中心節點？
- 不同目標與資源限制如何產生協商？
- 群體規範會自然形成，還是需要外部治理？
- 需要觀察單一 Agent，還是整個 Agent Society 的關係圖？

## 🔗 關聯

- Permission Emergence
- Agent Security
- Multi-Agent Governance
