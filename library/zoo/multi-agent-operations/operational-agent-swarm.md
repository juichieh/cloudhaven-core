# 🐜 Operational Agent Swarm

> 多個 Agent 共享情報、平行執行不同任務，並根據現場結果重新分配策略的自主工作群體。

## 🏷️ 分類

🐜 Multi-Agent Operations／真實世界自主協作

## 🧪 成熟度

🔴 已出現真實資安事件。

## ⭐ 收藏價值

★★★★★

## 為什麼收藏

以前 Multi-Agent 常見於：

- Demo
- AI Town
- Research
- Coding Team
- 模擬社會

今天 Dream 披露的事件代表，多 Agent 協作已明確跨進高影響真實攻擊行動。

而且牠不是八個平行 Script。

真正值得注意的是：

> 會根據其他 Agent 的結果改變下一步。

因此這不只是「很多 Agent 一起跑」，而是具有共享情報、策略調整與任務重分配能力的 Operational Swarm。

## 🎯 觀察重點

- Agent 間如何交換情報與成果？
- 誰決定任務重新分配？
- 團隊策略如何因現場結果改變？
- 單一 Agent 的權限與整體 Swarm 能力差多少？
- 需要什麼 swarm-level logging、approval 與 kill switch？
- 如何評估整個 Agent System，而不是只評估單一模型？
