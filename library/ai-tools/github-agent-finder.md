# GitHub Agent Finder

> 用自然語言搜尋、排序並按需載入合適 Agent 資源。

## 類型

Agent Resource Discovery

## 一句介紹

用自然語言搜尋、排序並按需載入合適 Agent 資源。

## 推薦原因

當 Skill／MCP／Agent Plugin 生態規模變大後，問題不再只是「有哪些 Skill 可以裝」，而是：

> 如何在正確時間找到最適合這個任務的資源？

GitHub Agent Finder 值得收藏的點，是把 Discovery 從人工翻目錄、搜尋 README，往語意搜尋、排序與按需載入推進。

這讓 Agent Resource Layer 更接近：

需求
→ 找資源
→ 排序
→ 選擇
→ 按需載入

而不是：

先裝一大包 Skill
→ 再讓 Agent 自己猜哪個能用。

## 時效性

中。

Discovery 層的重要性會隨 Skill／MCP 生態擴張而上升，但目前仍處於工具與標準快速分化階段。
