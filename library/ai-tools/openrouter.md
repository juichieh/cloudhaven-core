# OpenRouter

> 用單一 API 路由 400+ 模型，並幫 AI App 管理模型選擇與 usage。

## 🏷️ 類型

Model Routing / AI Infrastructure

## ⭐ 收藏價值

⭐⭐⭐

## 為什麼收藏

OpenRouter 的價值已不只是「方便一次接很多模型」。

更值得觀察的是它是否逐步成為：

- AI App 的模型路由層
- inference usage 聚合層
- 成本與 billing 管理層
- 多模型供應商切換與 fallback 層

如果 Stripe 收購後持續整合支付、計費與 inference infrastructure，它的定位可能從開發便利工具，升級成 AI inference / billing 基礎設施的重要候選。

## ⏱️ 時效性

高。

8/19 收購消息使其產品定位與後續整合方向值得持續追蹤。

## 🎯 觀察重點

- 模型選擇是否逐漸自動化？
- usage、成本與 billing 是否會成為同一層能力？
- 對 Agent Escalation Router / model routing 是否有直接參考價值？
- 在單一模型供應商失效或限流時，fallback 是否足夠成熟？
- routing policy 是否能與風險、品質、延遲、成本一起決策？

## 🔗 關聯

- Agent Escalation Router
- Guidance Layer
- Multi-model Infrastructure
- Agent Cost Control
- Model Evaluation
