# 🤖 Model Hardware Standard

> 嘗試建立讓 AI Agent 統一控制顯微鏡、機械手臂、實驗與製造設備的共同規格。

## 🏷️ 類型

Physical AI / Agent Interface

## ⭐ 收藏價值

⭐⭐⭐

## ⏱️ 時效性

高。2026-08-27 剛進入 Research Preview。

## 為什麼收藏

MCP 解的是：

> Agent 怎麼用軟體工具。

Model Hardware Standard 想解的則更接近：

> Agent 怎麼用物理工具。

如果未來能形成穩定規格，顯微鏡、機械手臂、實驗設備與製造機台就不必每次都做一次性的 Agent integration，而能逐步變成可描述、可發現、可控制、可治理的硬體能力。

這可能讓 Physical AI 的 integration cost 明顯下降，也讓「軟體 Agent」跨入「物理世界 Agent」時，不必每台設備都重新發明接線方式。

## 🎯 觀察重點

- 是否形成一致的 capability / command / state 描述？
- 不同廠牌設備能否透過同一抽象層被 Agent 控制？
- 安全界線如何處理：速度、力道、危險區域、實驗條件、緊急停止？
- 是否會與 MCP、A2A、Agent Card 或設備 Registry 形成互補？
- 真正的價值會落在標準本身，還是 SDK / driver / certification 生態？
- 是否能從實驗室設備擴展到製造、物流與一般機器人？
