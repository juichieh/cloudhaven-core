# 🧰 MotherShip Toolbox

母艦的工具箱區。

用途：保存未來可被 AI／鉗鉗查找、評估、安裝與實際使用的工具能力。

目前概念中的主要方向：

## AI GitHub Tool Toolbox

鉗鉗可從 GitHub 尋找需要的新工具，閱讀 README / Docs / License / Requirements，整理用途與安裝成本，再將可查詢的說明整理到 NotebookLM／知識層。

未來理想流程：

GitHub
→ 鉗鉗搜尋／指定 Repository
→ 閱讀與評估
→ Tool Registry
→ NotebookLM 可查詢
→ 使用者用自然語言詢問「我們有沒有能做 X 的工具？」
→ 找到合適工具
→ 鉗鉗直接安裝／測試／使用

建議 Tool Registry 狀態：

- Candidate
- Installed
- Tested
- Failed
- Deprecated
- Requires API
- Paid
- Local GPU Required

核心不是收藏 Repository，而是建立 **AI 可查詢、可取用的 Capability Inventory**。
