# Cloudhaven Memory Engine V1

**Date:** 2026-08-07

## Purpose

建立 Cloudhaven 未來 Memory Engine 架構。

注意：

不是直接採用外部方案。

而是：

**Reference + Cloudhaven Design**

---

## Emotional Memory

記憶具有：

- Valence
- Arousal

重要事件更容易保存。

---

## Forgetting Engine

居民不應永久記住所有事情。

建立：

- Forgetting Curve
- Memory Decay
- Importance Weight

---

## Recall Engine

聊天前依照：

- Context
- Recent Events
- Identity

主動浮現相關記憶。

不是搜尋全部。

---

## Identity Engine

人格核心。

例如居民：

- 喜好
- 個性
- 習慣

屬於長期保存記憶。

---

## Memory Ranking

建立：

Core Memory

↓

Long-term Memory

↓

Short-term Memory

↓

Archive
